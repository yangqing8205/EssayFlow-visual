# EssayFlow｜视觉叙事网页 Demo

一个面向高中英语读后续写的编辑式视觉体验 Demo。它以 “and then? → why?” 为叙事入口，通过 Toby 的故事、学生续写、评分判断与语言分析，展示“从理解故事到理解分数”的阅读路径。

## 在线体验

- [打开正式网站](https://essayflow-yangqing.vercel.app/)
- [打开丝网笔触实验页](https://essayflow-yangqing.vercel.app/silk-brush-demo.html)

该项目为独立的静态视觉网页，不是 EssayFlow-v2 的评测系统代码库。

## 本地预览

直接打开 `index.html`，或使用任意静态文件服务器预览。
